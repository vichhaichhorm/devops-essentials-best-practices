# Lesson 1: What Is DevOps?
===========================================================
1.1 Understanding DevOps in Simple English
*DevOps = Development + Operations
    . Development (Dev): The people who write and maintain software code.
    . Operations (Ops): The people who manage servers, deployments, networks, databases, and application availability.

*DevOps is a way of working that brings development and operations closer together through collaboration, automation, testing, and continuous improvement.

Example: Imagine your company has a Booking System.
The Operation Team requests a new feature:
 We want users to enter multiple container numbers in a single booking form.
The development team writes the code to implement this feature.
But writing the code is only one part of the job.

The company must also:
1-Review the code.
2-Test the feature.
3-Build the application.
4-Deploy it to the UAT environment.
5-Ask the team to test it.
6-Deploy it to production after approval.
7-Monitor the application to ensure it works correctly.

DevOps helps connect all these steps into one reliable workflow.

Without an organized process, developers might finish the code but forget configuration changes, deploy the wrong version, or cause problems in production.

With a good DevOps process, the team can make releases more consistent, reduce repetitive manual work, and detect problems earlier.

Remember this definition: ***DevOps is a combination of practices, collaboration, and automation that helps teams develop, test, release, and operate software more reliably and efficiently.
